## Verified facts (from partner sites)
- Handmade in Toronto, ships worldwide
- Process: 1) send logo/design → 2) quote + proof within 24h → 3) confirm proof, checkout → 4) built in 3–4 weeks (rush 1–2 weeks; fastest 24-hour builds available for limited styles)
- Custom pricing starts ~$400, varies by size/complexity
- 22 LED colours; acrylic cut options (regular, contour, cut-to-LED, box, table stand); UV printing; grid backings
- LED neon: shatterproof acrylic/silicone, 24V (vs 15,000V glass), 5–10x less energy, ~30,000hr lifespan, dimmers available
- Ships with mounting kit (screws flush / hanging wires / advertising nail), 12V power cord w/ switch
- 3-month electrical warranty
- Mediums: LED neon (commercial standard), EL wire (workshops, intricate portable), traditional glass (heritage)
- Workshops: groups 6–16, 1.5–2hrs, no experience needed, custom company logo add-on, phone-free format, Liberty Village studio (219 Dufferin St)
