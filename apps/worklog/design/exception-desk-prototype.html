Every row above is a real condition in the database right now, found through the MCP bridge — nothing here is illustrative. The design claim is narrow: this list is a work queue, not a filter and not a dashboard. A row only appears when a human decision is required, it carries the cost of leaving it alone, and it disappears when settled. Sorting a table cannot do that; sorting tells you the order of things you already knew.

The mechanism is one column. timers.last_seen_at is stamped by any authenticated request from that user while their timer runs — no desktop agent, no idle daemon, no new permission. On stop, the server compares the gap between last proven presence and the stop time; when it exceeds a threshold it writes the entry as state = 'provisional' and hands the human this dialog. Presence is proven, not absence detected — which matters, because the browser tab is not where the work happens.

The honest limit: if you spend the evening in Figma with the worklog tab closed, presence looks identical to absence. That is why the default is a choice, not an auto-truncation, and why “keep it all” is one click.

Model — the smallest change that carries it
TableChangeWhy
timersadd last_seen_at TEXT Presence is proven by any authenticated request while the timer runs. One column, no agent.
time_entriesadd state TEXT NOT NULL DEFAULT 'signed'
— 'provisional' | 'signed'		 Nothing provisional reaches a KPI, a budget bar or an invoice. Gives the Exception Desk its queue.
time_entriesbillable becomes billable_override INTEGER NULL Billability is derived from the project unless explicitly overridden — obeying the schema’s own stated law that derived values are computed at read time and never stored. This is what makes 13% and 100% agree.
time_entriessplit rows at local midnight on write An interval that crosses midnight becomes one row per day, so no calendar day can report more than 24 hours.
projectsadd contact TEXT; leave client alone The client column already holds contact names (Michael, Max Gregan, Elliot). Add the real field; do not rename an occupied one in place.
projectsno parent_id yet Group on the code prefix — 111 → 111-A…D, 222, 333. The hierarchy is already authored by hand and correct; validating the shape costs one line and no migration.

Sequence: derived billability and the Honest Stop ship together as one commit, because the Honest Stop writes entries and there is no point writing new ones under the old billable rule. The Exception Desk is built on top — it needs state to exist before it has a queue. Everything else is independent.
