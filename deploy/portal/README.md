# Deploy portal — deploy.dgtlmag.com

Token-auth zip-deploy service for the pitch host. Source recovered from the VPS
(`opt-dgtl-deploy`) — the engine skill and journal backlink kits reference this endpoint.

- POST a zip with `x-deploy-token` → slug-validated unpack to `PITCH_DIR/<slug>/`, size caps
  enforced, then the hub `index.html` is regenerated by `reindex()` — the hub is a build
  artifact, never hand-edit it.
- SPA fallback: include a zero-byte `.spa` file in the zip, or a `_redirects` line
  `/* /index.html 200`.
- Env: `DEPLOY_TOKEN` (required — live value is in the offboard bundle `env/dgtl-deploy.env`,
  never commit it), `PITCH_DIR` (default `/data/pitch`), `MAX_ZIP_BYTES`, `PORT`.
- `docker-compose.yml` still expects the origin host's `traefik-public` network + router labels —
  adjust for the new host. Serves the same pitch dir that `../decks/` (nginx) mounts read-only
  (see `../decks/docker-compose.override.yml`).
